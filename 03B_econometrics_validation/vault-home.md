# Econometrics Validation Vault

This is the Obsidian vault for the I(2)-trap validation project. Start with the
validation walkthrough, then navigate to the source evidence, canonical
concepts, and theory tasks through the scholarly index.

## Vault map

- `sources/` preserves immutable source snapshots and reviewed paper dossiers.
- `evidence/` holds the append-only NotebookLM audit, questions, and regenerated
  views.
- `concepts/` contains human-reviewed claims.
- `theory/` contains dependency-ordered derivations and simulation evidence.
- `bridges/` connects the evidence chain into reader-facing reports.
- `_meta/` records the note schema, provenance manifests, and migrations.
